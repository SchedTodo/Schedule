# 日程详情页展示修复设计

## 目标

在 Schedule v2 详情页完成三项展示修复：`rTime` 与 `exTime` 在每个 `;` 后换行且保留行末分号；增大星标按钮与 `Edit` 按钮的间距；让过期时间行在 Light 和 Dark 模式下都呈现清晰的灰色弱化效果。

## 设计

- 仅在详情页展示层格式化时间代码，不修改网关返回的数据，也不改变编辑弹窗的初始值。详情页使用一个本地格式化函数，将分号及其后的空白规范化为 `;\n`，并继续使用 `white-space: pre-line` 展示换行。
- 为星标按钮添加专用类，通过右侧外边距与后面的操作按钮组分隔。`Edit` 与 `Delete` 仍保留在现有按钮组中。
- 过期行继续由现有 `isPastOccurrence` 判断。样式使用项目主题变量 `--color-text-muted`，并覆盖单元格及其内部文本，使 Naive UI 的 Dark 主题文本样式不会遮蔽弱化色。

## 范围

只修改 `src/pages/schedule/[id].vue` 和对应的详情页单元测试。不会修改持久化、解析器、时间排序、过期判定、全局主题或其他列表。

## 测试与验收

- 组件测试验证包含多个时间表达式的 `rTime` 和 `exTime` 按 `;` 分行，并保留分号。
- 组件测试验证星标按钮使用独立间距类。
- 源码约定或组件测试验证过期行使用主题弱化色并覆盖单元格内部文本。
- 运行详情页相关测试、ESLint、Vue TypeScript 检查、完整单元/契约/解析器测试和 Web 构建。
